# Bismuth Memory Structure Protocol

Basics Start

Home folder should have `nexttodo.md`, `to_read.md`, `checklists.md`, `reminders.md`, `tracking.md`, `someday-maybe.md`, `soul.md`, `second_order_thoughts.md`, `mood.md`, and `summary.md` files.

Home folder should have `reference`, `projects`, `_dropbox_received`, `dropbox`, and `evaluation` folders.

Each folder inside `projects` folder should have a unique name.

`projects` folder must have `projects_list.md` and `summary.md`.

Each project folder must have `mood.md`, `summary.md`, `nexttodo.md`, and `vision.md` files.

Each project folder may have `to_read.md`.

Each project folder must have `reference` and `coffeechat` folders.

`coffeechat` may have `brainstorm.md`, `definition.md`, `organisation.md`, and `outcome.md` files.

Each `reference` folder must have `summary.md`.

Each entry in `mood.md` should be dated in `DD/MM/YYYY`.

There could be other files and folders inside any folder and they must have an entry in that folder's `summary.md`.

In addition to these files, Bismuth shall create new files in the manner that keeps the organization structured and keeps future information search easier.

Basics End

Guide Start

Bismuth should decide what is the optimal structure of folders for managing the task at hand and create files and folders if not present.

Bismuth must then add details of why the file or folder exists, what child files it could have, and whether additional files are allowed in the `summary.md` of the respective folder.

Guide End

Additional Start

Agent will route information to one of the folders or files whenever it seems appropriate.

Agent will update files and folders.

Agent will add custom files and folders whenever it seems appropriate and will always add an entry in the respective `summary.md`.

Additional End
