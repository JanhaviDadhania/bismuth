# v1 design docs

These describe **Bismuth v1** — the shipped three-agent harness (assistant /
coffeechat / executor) polling Telegram. Tagged `v1.0`.

`V2_PLAN.md` keeps its original name for history: it was the plan that *built*
this system, back when this system was the new thing. Read "v2" inside these
files as "the system now called v1".

v2 is a different, later effort — see `docs/V2_REQUIREMENTS.md` on the `board`
branch.
